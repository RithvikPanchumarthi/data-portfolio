# Overview

Modern responsive portfolio for Rithvik Panchumarthi — data engineering projects, built with React, Vite, and Tailwind CSS.

## Live demo

https://rithvikpanchumarthi.github.io/data-portfolio/

## Features

- Component-based React architecture
- Mobile-first Tailwind layout
- Fade-in / slide-up animations
- Project filtering by technology and category
- Formspree contact form
- Google Analytics + Microsoft Clarity
- Vite production builds

## Tech stack

| Layer | Choice |
| --- | --- |
| UI | React 18 |
| Bundler | Vite |
| Styles | Tailwind CSS |
| Icons | Lucide React |
| Forms | Formspree |

## Base path

Vite `base` is `/data-portfolio/`. Local URL is `http://localhost:5173/data-portfolio/`. Asset and image paths must respect this base.
