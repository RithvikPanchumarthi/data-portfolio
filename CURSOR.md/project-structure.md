# Project structure

```
data-portfolio/
├── CURSOR.md/               # Cursor agent docs
├── .cursor/skills/          # Project skills
├── .claude/                 # Claude Code: settings, launch config, skills (symlinks)
├── public/                  # Static assets (also copied under base path)
├── scripts/
│   └── sync-github.mjs      # Writes src/data/github.json (run in CI before build)
├── src/
│   ├── components/
│   │   ├── Header.jsx       # Sticky identity + quote bar + corner nav from `sections` in App.jsx
│   │   ├── GrainOverlay.jsx # Film-grain overlay
│   │   ├── Hero.jsx         # LinkedIn headline, location, Resume & Links + Building with AI stats (no name H1)
│   │   ├── About.jsx        # Editorial about + skills list (no project plates)
│   │   ├── Experience.jsx   # LinkedIn data; hidden until profile.js is filled
│   │   ├── Projects.jsx
│   │   ├── GitHubActivity.jsx
│   │   ├── LearningJourney.jsx
│   │   ├── BuilderStats.jsx # Cursor / AI stats; rendered inside Hero
│   │   ├── Contact.jsx      # Formspree form + footer
│   │   ├── DetailModal.jsx  # Shared accessible modal
│   │   ├── Reveal.jsx       # Framer Motion scroll-reveal wrapper
│   │   └── SectionHeader.jsx
│   ├── data/
│   │   ├── projects.js      # Curated project cards
│   │   ├── github.json      # Generated by scripts/sync-github.mjs — don't hand-edit
│   │   ├── profile.js       # LinkedIn export data
│   │   ├── aiStats.js       # Cursor stats + AI workflow copy
│   │   └── learning.js      # Learning journey timeline
│   ├── hooks/
│   │   ├── useActiveSection.js
│   │   ├── useScrollVisibility.js
│   │   └── useReveal.js
│   ├── utils/
│   │   └── format.js        # Compact numbers, relative dates
│   ├── App.jsx
│   ├── main.jsx
│   └── index.css            # Cream-light tokens, grain, editorial type
├── package.json
├── tailwind.config.js
├── vite.config.js
└── netlify.toml
```

## Where to edit

| Change | File(s) |
| --- | --- |
| Project cards | `src/data/projects.js` |
| GitHub section data | `npm run sync:github` (never edit `src/data/github.json`) |
| Experience / certifications | `src/data/profile.js` |
| Cursor / AI stats | `src/data/aiStats.js` |
| Learning timeline | `src/data/learning.js` |
| Nav items / section order | `sections` in `src/App.jsx` |
| Contact / social | `src/components/Contact.jsx`, `src/components/Header.jsx` |
| Hero copy | `src/components/Hero.jsx` |
| About | `src/components/About.jsx` |
| Colors / type | `tailwind.config.js`, `src/index.css` |
| Deploy base path | `vite.config.js` |
